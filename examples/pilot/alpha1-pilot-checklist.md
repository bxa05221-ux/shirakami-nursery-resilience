# Alpha 1.0 Pilot Readiness Checklist

## Before data entry
- [ ] Use synthetic data only.
- [ ] Confirm facility-specific staffing and capacity rules are documented separately.
- [ ] Confirm identity mapping is outside the public repository.
- [ ] Confirm authorized roles and access boundaries.

## Runtime smoke
- [ ] Reference runtime compiles.
- [ ] Synthetic dataset loads.
- [ ] Presence/time landscape is generated.
- [ ] External time windows are generated.
- [ ] Human-readable pilot report is generated.

## Decision boundary
- [ ] AI proposals are visibly separated from human decisions.
- [ ] Safety and staffing decisions require human confirmation.
- [ ] Forecast source and uncertainty remain visible.

## Evidence
- [ ] Observation has provenance.
- [ ] Human decision is recorded separately.
- [ ] Corrections preserve the original event.
- [ ] External evaluation export is anonymized.

## Exit
- [ ] Known gaps are recorded.
- [ ] No real personal data has entered the pilot.
- [ ] Pilot findings are treated as observations, not proof of production safety or regulatory compliance.
