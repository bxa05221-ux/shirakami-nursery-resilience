# 保育レジリエンス α1.0 — スマホ実証デモ

## 目的
職員がスマートフォンから日々の観測を入力し、Landscapeを確認し、翌日の保育計画案を作成・修正・承認する一連の流れを実演する。

## デモフロー
1. `web/index.html` を開く。
2. 6クラスから対象クラスを選択する。
3. 子どもの姿を「解釈」ではなく、まず観察事実として入力する。
4. 必要に応じて子どもの選択・声を入力する。
5. 出席人数と配置職員数、配置・環境上の気づきを入力する。
6. ヒヤリハット、インシデント、安全・権利擁護上の懸念等をSafety Signalとして記録する。
7. 「現在のLandscapeを表示」で個別・クラス・配置・Safetyを確認する。
8. 位相を「個別→集団→園→外部」「過去→現在→明日」と回転させて考える。
9. 「計画案を生成」で翌日の保育計画ドラフトを作る。
10. 職員が修正し、「保育者確認・承認」で確定履歴を残す。

## α1.0での重要な境界
- AIは保育者の判断を代替しない。
- 生成物は必ず人間が確認・修正・承認する。
- 虐待等の重大なSafety SignalはAIが判定主体にならず、所定の人間による初動、報告、関係機関との連携を優先する。
- 現在のWebデモは端末のlocalStorageを使うプロトタイプであり、実施設の個人情報を保存する用途には使用しない。
- 本番化には認証、権限管理、暗号化、監査ログ、バックアップ、データ保持・削除方針、施設ごとの制度・運営Policyが必要。

## 次段階
`web/index.html` のlocalStorage実装を `api/openapi.yaml` のAPIへ接続し、認証・権限・永続DBを備えたReference Runtimeへ移行する。
