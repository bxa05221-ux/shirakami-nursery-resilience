# 保育レジリエンス α1.0 — 出力フォーマット

## 1. 設計方針

システムは記録を増やすのではなく、同じLandscapeから必要な成果物を派生させる。

`観察 → Landscape → 計画 → 実践 → Evidence → 振り返り → 翌日の計画`

AIはドラフトを生成する。最終的な承認・判断は保育者、管理者、必要な専門職が行う。

## 2. 運用規模

- クラス数：最大6クラス
- 1クラス：最大20人
- 最大登録児童数：120人
- 個別保育計画は各児童単位で保持する

## 4. 3D位相回転による出力切替

同じ観測から、以下の3軸を切り替えて出力する。

### 時間軸
`過去 → 現在 → 翌日`

### スケール軸
`個別 → クラス → 園 → 外部環境`

### 行動軸
`観察 → 計画 → 実践 → 評価 → 改善`

したがって同じ事象について、個別計画にも、クラス計画にも、安全記録にも、第三者評価Evidenceにも変換できる。

## 5. 出力の原則

1. 事実とAIによる仮説を明示的に分ける。
2. AI生成物は「案」として扱う。
3. 人間の確認・修正・承認を保存する。
4. 安全・人員配置・専門判断をAIだけで決定しない。
5. 同じEvidenceから複数の文書を生成し、二重入力を減らす。
6. 第三者評価から得た改善提案を、次の保育計画へ逆流できるようにする。
