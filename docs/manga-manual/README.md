# 漫画マニュアル — 保育レジリエンス α1.0

## なぜ漫画なのか

本システムは、操作説明だけではなく「保育の見方そのもの」を現場で共有するためのマニュアルを必要とする。

文章マニュアルは制度・機能・注意事項を説明する。漫画マニュアルは、**現場で起きる場面、保育者の迷い、子どもの姿、Landscapeの変化、翌日の保育への接続**を短時間で共有する。

## 基本方針

- AIが保育を決めない
- 子どもを問題化しない
- 一斉保育を否定して導入しない
- 個別の観察から集団Landscapeを組み立てる
- 記録を増やすのではなく、一つの観察から必要な記録を派生させる
- 職員の判断と修正を必ず残す
- 外部情報は判断材料として提供し、AIが安全判断を代行しない
- 匿名通報は通常の保育記録から分離し、通報者保護と権限管理を優先する

## 漫画シリーズ構成

### 第1話「いつもの一斉指示」
現場の職員が一斉指示を繰り返している。誰も悪くないが、保育者も子どもも疲れている。

### 第2話「その子が動けない理由」
同じ指示でも反応が違う。子どもの行動を「従わない」ではなく観察する。

### 第3話「Landscapeを置いてみる」
観察を、発達・興味・関係・環境・援助量などの文脈と一緒に記録する。

### 第4話「みんなの景色がつながる」
複数の子どもの個別Landscapeがつながり、集団の関係性が見えてくる。

### 第5話「明日の保育を少し変える」
AIが計画案を提示する。保育者が修正し、承認する。AIは決定者ではない。

### 第6話「先生が楽になった」
一斉指示を増やすのではなく、環境を変えたことで子どもの自主的な活動が増え、保育者の直接介入が減る。

### 第7話「園の外もLandscape」
天気、警報、害獣出没、防災情報などを園内Landscapeと重ねる。

### 第8話「声を上げられる場所」
匿名内部通報を、告発ではなく安全・組織改善のSignalとして扱う。ただし通報情報は厳格に分離・保護する。

### 第9話「園全体を逆から見る」
日々のEvidenceを第三者評価の視点から読む。評価結果は改善計画へ戻る。

### 第10話「明日の景色へ」
個別 → 集団 → 園 → 評価 → 改善 → 個別、という循環が一本につながる。

## 1ページの基本レイアウト

1. **場面** — 現場で何が起きているか
2. **違和感** — 保育者が感じる小さな引っかかり
3. **観測** — 子どもの姿を具体的に捉える
4. **Landscape** — 関係・環境・発達・外部情報をつなぐ
5. **問い** — スレゼンターが答えではなく問いを返す
6. **人間の判断** — 保育者が計画を修正する
7. **翌日の実践** — 環境・援助・配置を少し変える
8. **変化** — 子どもと保育者の姿を再観測する

## 漫画内でのスレゼンター

スレゼンターは「先生に命令するAI」ではない。

漫画では、画面の端に現れて、観測された情報を短く束ね、次の問いを投げる役割として描く。

例：

> 「『できない』ではなく、『どの条件ならできた？』を見てみませんか？」

> 「この子の反応と、環境の変化を一緒に見ると何が見えますか？」

> 「明日の保育で、一つだけ変えるなら何にしますか？」

## 禁止する描写

- AIが診断する
- AIが保育方針を一方的に決める
- 子どもを「問題児」として描く
- 匿名通報者を特定可能にする
- 天候・害獣情報からAIが自動で活動可否を決定する
- 第三者評価を「監視」や「査定」だけとして描く

## 位置づけ

この漫画マニュアルは、機能説明書ではない。**保育者が本システムを使い始める前に、Landscape Firstの考え方を共有する導入教材**である。
